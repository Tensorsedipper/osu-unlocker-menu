## 🧩 About

**osu! catalog Menu** is a curated list of osu! open-source tools:

- **Overlays** — on-screen helpers, layout notes, beatmap viewer, cursor trail notes
- **Quality-of-Life Helpers** — skin catalog, profile notes, overlay configs
- **Research Notes** — practice layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### 🎮 Practice Helpers
- Beatmap Viewer — inspect patterns from any checkpoint
- Show Hitboxes — visualize hit circles and slider paths
- Replay Notes — record and review play runs
- Playback Speed — adjust editor playback for study (0.1x to 5x)

### 🎨 Catalog & Cosmetics
- Skin Catalog — browse skins, cursors, trails, hitsounds
- Custom Skin Notes — organize player cosmetics
- Cursor Trail Notes — improved visibility during study

### 🏋️ Practice Layout
- Practice Mode Notes — segment study on any map
- Timing Control Notes — manually review timing windows
- Stream Buffer Notes — chain complex patterns in the editor
